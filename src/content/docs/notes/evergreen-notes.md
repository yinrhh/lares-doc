## 一句话

常青笔记是**为自己的思考服务**的笔记：每一页只讲一个概念，用自己的话写，并且会随理解加深不断被改写。

## 它反对什么

大多数人做笔记的方式是「按来源收集」：一篇文章一篇笔记，一本书一篇笔记。这种笔记的问题不是写得不好，而是**它不会被再读第二次**——因为下一次遇到同一个概念时，你找不到它。

收集是输入端的动作，理解是输出端的动作，两者不能互相替代。

## 三条判据

判断一页笔记是否常青，只问三个问题：

1. **原子吗？** 这一页能不能被另一页单独引用，而不需要上下文？
2. **概念化吗？** 标题是「XX 是什么 / 为什么」，而不是「第 3 章读书笔记」？
3. **连得上吗？** 有没有至少两条指向别的笔记的链接？

## 与每日笔记的关系

两者不是二选一，而是流水线：

| | 每日笔记 | 主题笔记 |
| --- | --- | --- |
| 时间粒度 | 一天 | 无期限 |
| 主要作用 | 捕获、不遗忘 | 沉淀、可复用 |
| 成熟度 | 一次写完，不回改 | 持续改写 |
| 失败模式 | 断更 | 变成只收集不消化的仓库 |

每日笔记里反复出现的概念，就抽出来单开一页主题笔记——这就是这个库 `notes/` 目录的来源。

## 我的实践

- 每日笔记里只写「今天懂了什么」，不写大段摘抄
- 同一个概念第三次出现时，才值得单开一页
- 主题笔记不做删除，只做改写或归档（`status: archived`）
