每日笔记记录「今天发生了什么」，主题笔记沉淀「我到底搞明白了什么」。

一页讲清一个概念，单独拿出来也能看懂；不随时间腐烂，只随理解加深而迭代。

## 状态标记

| 状态 | 含义 |
| --- | --- |
| `seeded` | 刚记下，还不完整 |
| `growing` | 在生长，持续补充中 |
| `evergreen` | 稳定可用，能直接复述给别人听 |
| `archived` | 已被新认知取代，留作追溯 |

## 已有的笔记

见左侧「主题笔记」分组，或直接用搜索（`Ctrl` / `⌘` + `K`）。

新建一页：

```bash
npm run note -- "Rust 所有权" --tags rust,memory
```
