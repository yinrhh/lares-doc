## 收录标准

只收**自己真的用过、并且愿意推荐给别人**的东西。三条门槛：

- 能解决具体问题，不是「看起来很厉害」
- 说得出适用边界，或者前置要求
- 一句话讲清好在哪里

「在学」「搁置」的资源也留着，比只留好评更诚实。

## 分类

| 分类 | 收什么 |
| --- | --- |
| [课程与讲座](./courses/) | 系统课、公开课、技术讲座 |
| [书籍](./books/) | 教材、专著、小册子 |
| [文章与博客](./articles/) | 单篇好文、长期跟读的博客 |
| [工具与文档](./tools/) | 官方文档、开发工具、效率工具 |

## 加一条记录

```bash
npm run resource -- --category books --title "深入理解计算机系统" --url https://csapp.cs.cmu.edu/
```

会新建一条表行，之后手动补评分和评价即可。

评分口径：`⭐⭐⭐⭐⭐` 只有「改变了我做事方式」才给。
